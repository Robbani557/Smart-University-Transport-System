Place icon/image assets here (e.g. dashboard.png, student.png, admin.png,
transport.png, report.png, logout.png, bus.png, bell.png, user.png).

IconUtils looks for files in this folder on the classpath (/images/...).
If a file is missing, IconUtils generates a safe fallback icon instead of
crashing, so the app runs fine even before real assets are added.
